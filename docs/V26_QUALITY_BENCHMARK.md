# V26 质量 / 效率前后对比

本页记录 V25 基线与 V26 当前代码在 **同一组离线样例** 上的可重复对比。所有搜索/图片调用均为 Mock，不消耗 Tavily、Serper 或 DeepSeek 额度；Prompt 采用字符数作为 Token 体积代理，因此不宣称等同于真实 Token 账单。

## 1. 检索语义分离度

分数越高表示越匹配用户主题。重点看“相关结果 - 假阳性结果”的 margin。

| 查询 | V25 正例 | V25 假阳性 | V25 margin | V26 正例 | V26 假阳性 | V26 margin |
|---|---:|---:|---:|---:|---:|---:|
| 数据在技术突破上的作用 | 56 | 34 | 22 | 86 | 0 | 86 |
| 数据资产入表对企业融资有什么作用 | 74 | 33 | 41 | 100 | 8 | 92 |
| 可信数据空间如何促进产业协同 | 72 | 17 | 55 | 100 | 8 | 92 |

其中第一组假阳性是“数据中心液冷技术取得新突破”。V25 因“数据 + 技术突破”字面重合仍给出 34 分；V26 要求关系查询覆盖“数据使用/赋能”与“技术突破”两个语义侧，因此降为 0。

## 2. 主检索与 Serper 调用预算

对于“数据在技术突破上的作用”，新闻 + 普通网页 + 国际补充 + 政策 + 论文的 Tavily 主检索通道：

- V25：**5 次**；
- V26：**5 次**。

V26 没有为了增加语义变体额外增加主检索请求；提升来自更好的 Query 与本地语义门禁。

同样给定 3 个 Serper fallback 候选搜索词：

- V25：Web + News 对每个词各跑一次，共 **6 次**；
- V26：2 个互补 Web + 主 Query 1 个 News，共 **3 次**。

减少 50% 的 fallback 请求，同时保留 Web 普通网页通道，因此不会为了省调用退化成只搜 News。

## 3. 图片搜索预算

| 场景 | V25 初始 Serper Images | V26 初始 Serper Images |
|---|---:|---:|
| 没有来源页原图 | 2 | 1 |
| 已有引用来源页原图 | 1 | 0 |

V26 只在首轮候选不能通过语义/可下载性门禁时再执行一次真正不同的回退 Query。

## 4. 首稿 Prompt 体积代理

固定 6 条超长来源、相同主题与篇幅：

- V25：24,298 字符；
- V26：13,318 字符；
- 下降约 **45.2%**。

减少的主要是来源正文噪声与重复控制说明，不减少用户写作规格，也不降低正文目标篇幅。

## 5. 当前质量门禁

V26 离线基准必须同时满足：

- 三组语义测试最小 margin ≥ 40；
- Tavily 主检索固定样例 ≤ 5 次；
- Serper fallback ≤ 3 次；
- 无源图首轮 Images ≤ 1 次；
- 有源图首轮 Images = 0 次；
- 首稿 Prompt 体积代理 < 16,000 字符。

运行：

```bash
PYTHONPATH=. python scripts/quality_benchmark.py
```

当前基准结果：全部通过。

## 6. 回归测试

当前自动化测试覆盖检索、来源核验、写作去模板化、图片来源绑定、来源图位置保护、导出、前端等高布局等关键路径。V26 当前测试结果：**85 passed**。
