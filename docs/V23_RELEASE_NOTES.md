# V23 Release Notes

V23 是一次针对“生成推文”全链路的整改，目标是解决自动资料没有真正进入写作、正文配图偏题、封面缺失、默认结构 AI 味过强，以及 PDF/DOCX 与网页预览视觉落差大的问题。

## 自动资料

- 前端 `/api/search` 同时传入主题与写作切口。
- 前端检索 0 条或发生可恢复错误时，不阻断生成；服务端继续自动研究。
- 服务端自动研究采用 relevance-first + 一次有限放宽，并把最终来源同步回生成页证据列表。

## 写作

- 默认结构改为 0—3 个自然小标题优先，可完全无小标题。
- 识别并修复“问题/做法/机制/影响/条件/判断”式 AI 六段论。
- 默认结构出现四个以上整齐章节时触发编辑修复。
- 默认标题、开头、段落、证据和结尾继续保持“编辑自由”，不映射到隐藏模板。

## 图片

- 封面固定由标题 + cover brief 生成编辑设计图，不计正文图片数量、不消耗 Serper。
- 正文图片查询绑定全文主题、当前章节和相邻正文。
- 数据主题要求候选元数据自身包含数据、模型、算法、机器学习、AI、仿真、数据平台等语义。
- 对消费电子评测、纯技术结构图等“只有研发/科技感但没有文章语义”的图片加强拒绝。
- 有匹配原新闻/政策来源时仍优先原文配图；找不到足够相关图片时留空，不凑图。

## 导出

- DOCX 重新校准 A4 页边距、主标题/小标题/正文/图注尺度与中文行距。
- ReportLab PDF 使用与网页/DOCX 接近的字号与版心。
- Pillow PDF fallback 全面重写：黑体/宋体分工、约 11pt 正文、首行缩进、图注、分页和页脚重新校准。
- 已对 DOCX、ReportLab PDF、fallback PDF 逐页渲染检查。

## 验证

- 61 个单元/回归/服务 smoke tests 全部通过。
- 全部前端 JavaScript 通过 `node --check`。
- Python 通过 `compileall`。
