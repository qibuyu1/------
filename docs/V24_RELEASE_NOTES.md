# V24.0 发布说明：检索召回与源新闻配图专项整改

本版本只针对用户本轮指出的两个核心质量问题动刀：**长自然语言 Query 搜不到**，以及**正文图片无法优先回到源新闻/源材料**。封面生成逻辑保持不变。

## 1. 长 Query 不再按整句硬搜

旧逻辑对“数据在技术突破上的作用”这类自然语言问题，会把整句同时放进：

- Tavily 新闻 Query；
- `mustTerms`；
- 本地相关性门禁。

因此真实结果即使标题写成《数据要素赋能企业关键核心技术突破研究》，也会因为没有逐字出现“数据在技术突破上的作用”而得到很低的本地分数，最终被过滤成 0 条。

V24 新增本地概念拆解：

`数据在技术突破上的作用 -> 数据 + 技术突破`

并自动生成短查询改写，例如：

- `技术突破 数据`
- `数据要素 技术突破`
- `数据赋能 关键核心技术突破`
- `数据驱动 技术创新`
- `数据科技创新`

原始长句仍保留为一条语义补充通道，但不再是硬匹配条件。

## 2. 增加“浏览器式网页检索”通道

Tavily `topic=news` 适合近期主流新闻，但很多中文政策解读、行业文章、学术网页并不属于 News 垂类。V24 对长自然语言/关系型 Query 额外并行执行一次 `topic=general + country=china` 的普通网页检索，再按页面特征归入新闻、政策或论文。

这使网站的行为更接近用户直接在浏览器搜索：能同时召回政府页面、产业媒体和学术网页，而不是只盯新闻垂类。

为控制速度与调用量，概念型 Query 会跳过价值较低的“权威新闻域名重复查询”，改为：

`开放新闻 + 普通网页` 并行。

## 3. Serper 兜底改为网页 + 新闻并行

Tavily 候选不足时，Serper 不再只调用 News endpoint。

现在最多取 3 条短 Query，并行执行：

- Google Web Search；
- Google News Search（用户勾选新闻时）。

结果统一去重、分类、相关性评分和来源校验。这样像学术期刊页、国家数据局专家解读、产业研究网页等普通 Google 搜索能找到的页面，不会因为“不在新闻索引”而完全消失。

## 4. 正文图片优先从“实际采用的来源页”拿

生成文章前，系统本来就会批量抽取最终采用的证据页。V24 在同一次 Tavily Extract 请求中开启 `include_images=true`，把来源页真实图片一并带回，不再先写完文章后完全依赖二次图片搜索。

链路变为：

`最终采用来源 -> Tavily Extract 正文 + 来源页图片 -> 章节/案例匹配 -> 图片尺寸/热链/重复检查 -> 优先使用来源原图`

只有来源页没有合格图片或章节没有匹配来源时，才依靠 Serper / Google Images 补充。

## 5. Serper 图片检索更像“找原报道”，不是堆泛词

当章节能匹配到已采用来源时：

1. 首条图片 Query 使用**原文标题 + 来源媒体**；
2. 不再强制追加“原文 配图”这类索引页通常不会出现的词；
3. 第二路才使用“数据驱动 / 科研 / 技术创新 / 数据分析”等章节语义；
4. 无来源时允许使用与数据、科研、模型、数据平台直接相关的科技实景/数据可视化图片，但仍要求候选元数据出现数据/模型/AI/分析等锚点；
5. 笔记本评测、显卡、CPU、纯材料结构图等弱相关图片继续被拦截。

来源页图片在语义合格时有额外排序加权，因此会优先于普通图片搜索结果。

## 6. “配图与来源”面板统一展示全部最终图片

该面板现在会直接显示：

- 文章封面；
- 每一张正文图片缩略图；
- 图片放置位置；
- `源新闻/源材料原图` / `Serper / Google Images` / `系统封面` 标记；
- 来源名称、来源链接、匹配分和实际尺寸；
- 每个参考来源已抽取的来源页图片候选数量。

正文没有找到合格图片时仍然留空，不用无关图凑数。

## 7. 回归验证

V24 新增回归用例覆盖：

- “数据在技术突破上的作用”自动拆成浏览器式短 Query；
- 《数据要素赋能企业关键核心技术突破研究》不再被本地门禁误杀；
- 概念型 Query 会调用普通网页发现通道；
- 未配置 Serper 时，只要来源页已有合格原图，正文仍可正常使用；
- Tavily Extract 会真实请求来源页图片；
- 原有导出、生成、排版和图片热链回归测试继续通过。

当前测试：`65 passed`。
