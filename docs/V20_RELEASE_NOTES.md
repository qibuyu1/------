# V20.0 发布说明

## 整改目标

本版本针对“检索结果为 0、国内资料不足、国际资料偏题、首页暴露系统失败话术、项目压缩包缺少完整根目录”五类问题完成重构。

## 检索链路

1. 解析主题、附加描述、排除项、来源偏好和地区范围。
2. 默认以国内优先策略并行检索：
   - 政府与权威媒体域名；
   - 国内开放新闻与产业案例；
   - 国家及地方政策；
   - 中文论文；
   - 少量国际补充。
3. 先执行主题相关性门禁，再对高排名候选读取原文页面。
4. 页面读取成功的结果标记“已核验原文”；页面因反爬或访问控制无法自动读取、但由检索索引明确定位且相关度达标的结果标记“已定位原文”。
5. 标题不一致、聚合页、错误页、无效链接和 404/410 结果直接剔除。
6. 结果按主题匹配、来源权威度、时效性、地区优先级综合排序，并应用地区配额。

## 前端体验

- 新增地区范围控制与检索策略面板。
- 默认“综合匹配”排序，展示新闻/政策/论文、国内/国际、核验/定位统计。
- 搜索索引来源可以打开原文并由用户明确引用；自动佐证仍只使用已核验原文。
- 首页无推荐时显示真实专题入口，不伪造新闻，也不展示自我否定文案。
- 首页专题与推荐标题进入查询页后自动发起检索。
- 空状态、进度和异常提示统一为专业、可操作的表达。
