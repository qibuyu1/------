# 数据要素治理 V18.0

本版本重点解决“用户需求没有真正进入检索与写作”的根问题。

## 检索

- 新闻与论文查询新增“附加描述”，用于描述地区、时间、来源偏好、排除项和检索方式。
- 当用户填写附加描述时，使用 DeepSeek V4 Flash 的非思考、低 token 查询意图分析器，把描述转换成：核心主题、必须命中词、锚点词、排除词以及新闻/政策/论文的专用查询句。
- 查询结果先做用户意图相关性门禁，再做来源可访问性/canonical/标题验证，最后综合排序；不再让 Tavily provider score 单独决定结果。
- 对宽泛关键词（例如“数据”）增加领域锚点约束，避免无关行业结果混入。
- 政策、论文查询不再偷偷追加固定“数据要素/数据治理”词；由意图规划生成具体检索句。
- 论文检索不再强制中国 country 偏置，保留国内外学术来源。
- 来源验证优先使用页面的 canonical、title、meta description；页面错误提示、验证码、聚合页、导航页会被过滤。
- 结果摘要优先使用经来源页验证的 meta description，避免把搜索提供商的无关摘要或验证码提示直接展示给用户。
- 首页推荐采用简短主题查询，统一经过真实来源验证、相关性门禁和重复报道去重。
- 首页缓存 key 升级，旧版本的无关推荐不会继续复用。

## 写作

- “写作切口 / 用户实际要求”明确作为最高优先级编辑简报。
- DeepSeek 生成结果新增 `understoodBrief`，用于展示系统对用户真实写作意图的理解，但不会进入正文。
- 提示词明确要求把用户意图落实到标题、开头、主体取舍、章节顺序和结尾，而不是复述要求。
- 保留原有字数、受众、风格、标题、结构、开头、节奏、证据、结尾等控件，并继续通过本地质量门禁校验。

## 成本与速度

- 查询意图分析仅在存在附加描述时调用，且使用 DeepSeek V4 Flash 非思考模式并缓存 15 分钟。
- 首页推荐直接走本地查询计划，避免因为首页自动刷新增加多余模型调用。
- 搜索结果阶段不使用 DeepSeek 生成答案，不再展示可能偏题的 provider answer。

## 可用性

- 新增检索需求理解区，用户能看到系统对查询描述的理解。
- 查询结果评分细节增加“为什么匹配”。
- 旧搜索快照和首页缓存版本化，避免升级后旧错误结果继续污染页面。
