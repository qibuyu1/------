## 2. 调用与速度约束

- 无源图且首条命中：V26 = 1 次 Serper Images；V27 = 1 次。
- 无源图首条失败：V26 上限 = 2 次；V27 上限 = 2 次。
- 已有可用来源页图片：V26 = 0 次；V27 = 0 次。
- Tavily 未返回源图但有来源 URL：V27 会并行读取来源页图片元数据；不消耗搜索 API 调用或 LLM Token。
- 多个缺图位的第二轮检索与下载探测由串行改为全局并行。

## 3. 候选覆盖

- V26 首轮每个位置实际探测排序前 4 个候选；V27 提升为前 7 个。
- V26 存在“来源页第 5/6 张图片允许通过语义规则，但根本没有被下载探测”的盲点；V27 已消除。
- 单次 Serper Images 候选池由 14 增至 18，不增加请求次数。
