# V29.0 二维码硬拦截与配图精准度修复

## 背景

V28 已能稳定回源新闻图片，但真实页面暴露了两个新的质量问题：

1. 某些中文媒体把“关注公众号二维码”放进 OpenGraph 或正文前排大图，图片尺寸足够大、URL 又是随机 CDN 哈希，因此仅靠 URL/尺寸规则会误当作正文配图。
2. 某段正文已经在讲“仓库入库与库存数据”，Google Images 仍可能返回“AI 汽车识别”这类只与文章总主题沾边的泛科技图。

## 修复

- 新增 Pillow-only QR 视觉检测：近二值像素比例 + 1:1:3:1:1 finder pattern + 转换密度；无需 OCR/OpenCV/模型调用。
- 来源页解析提前过滤二维码、扫码、微信/公众号、follow 卡等文本信号。
- 媒体/机构根首页不再作为 exact evidence page，避免主页 `og:image` 和首页推广资源获得源图加权。
- 新增仓储/库存、供应链、制造、销售/订单、财务、医疗、交通等局部视觉路由。
- 对具备具体段落场景的 Serper 候选增加 local-scene gate；仅命中“数据治理/AI”总主题不再足够。
- 保留 V28 的来源原图优先、图片位公平探测、并行补搜和调用预算控制。
