## 2. 每处改动要点（按 A–F 优先级）

**A. 标题层级（`build_docx` 标题块、`_build_pdf_reportlab` 样式）**
- 主标题：`Title` 21pt 黑体、近黑 `#1A1A1A`、加粗，段后 6pt。
- 副标题/导语（`deck`）：12pt 宋体、强调蓝 `#0B57B7`，紧跟主标题（公众号式的引导语，而不是原先 10.5pt 灰摘要）。
- 眉行：品牌 + 日期 9.5pt 灰 `#6B7280`，下加一条细线规则。
- **保留文章原生小标题层级**：`#`→Heading 1、`##`→Heading 2、`###`→Heading 3（原先 `##`/`###` 全折成 Heading 2）。**未**引入周报的 01/02 编号，也**未**添加"数治观察"栏目框。标题段前后距 16pt/8pt，keep_with_next 防孤行。
- PDF 侧新增 `_heading_style_for()` 按 level 选 15.5/14.5/13.5pt，保留三级层次。

**B. 中文正文（`build_docx` Normal 样式 + 正文段）**
- 正文字体：宋体/SimSun。`Normal` 字号 11.2pt→**12pt（小四）**，颜色 `#1C1C1C`→**深蓝灰 `#172033`**。
- 行距 1.68→**1.6**（>=1.5 要求，CJK 阅读更稳），段后距 7.5pt→9pt。
- 首行缩进 = **2 全角字符（2×12pt=24pt，`w:firstLine=480`）**。
- **两端对齐**：正文/列表段加 `WD_ALIGN_PARAGRAPH.JUSTIFY`（`w:jc both`），消除右缘参差。
- 孤行控制：`widow_control` 保留；PDF 用 leading=20 与 justify。
- 字体检测沿用 `_find_cjk_font/_load_cjk_font` 与 Noto CJK 分支，未改动。

**C. 配图与说明（`_docx_add_image`、`_pdf_image_flowables`、新增 `_figure_caption`）**
- 页面设为 **A4**（8.27×11.69in），页边距上0.72/下0.68/左右0.82in，由 `content_width` 计算可用列宽（≈6.63in），图片按列宽定宽、按 `max_height` 限高（封面 4.1in、正文 5.4in）**保持原图比例**。
- 配图说明：统一走 `_figure_caption()` —— 优先取已有说明（已带"图片来源："），否则由"描述 + 来源"合成 **"图片来源：{描述}（来源：{来源}）"**；说明段 8.5pt、灰 `#6B7280`、居中，段前 2pt 段后 9pt，keep_together，避免被压扁或溢出。
- `_caption_for()`（content_blocks）与 `_visual_caption()`（pipeline）同步改为"图片来源："前缀，保证浏览器预览 / DOCX / PDF 三种载体说明一致。

**D. 来源/资料来源标注（`build_docx` 来源段、`_build_pdf_reportlab` source_style）**
- 由原先的大号 `Heading 2`+"参考来源"改为**小而淡的"资料来源"块**：标题 11pt 灰 `#6B7280` 加粗，每条 8.5pt 灰、左缩进 0.15in、行距 1.25、段后 2pt；链接用含蓄的 `#60778A`，不抢正文，视觉收敛、不突兀。PDF 侧 `source_style` 同样 8.5pt 灰 `#6B7280`。

**E. 分页与页眉页脚（`build_docx` 页脚、A4 页面、PDF 字体）**
- A4 页面 + 标题/正文 keep_with_next/keep_together，图片不孤悬页末。
- DOCX 页脚改为居中横幅 `— 数据要素实验 · 聚焦数据要素治理与价值释放 —` 8pt 强调蓝 `#0B57B7`。
- ReportLab PDF 用 CID 字体 `UnicodeCIDFont("STSong-Light")`（已验证 `STSong-Light` 出现在 PDF 字节中），标题走位图着色字体表；`_pdf_heiti_title_image` 已包在 try/except，缺字体时安全回退 STSong 文本。

**F. 可见 bug 修复**
- `_xml_escape()`：新增 `_INVALID_XML_CHARS_RE`，先剥离 XML 1.0 非法控制字符（`\x00-\x08\x0b\x0c\x0e-\x1f\x7f`）再转义，避免正文含非法字节时整个 document.xml 损坏。
- `_docx_picture_xml()`：去掉硬编码 `cx=6000000 cy=3375000`，改为由调用方传入 EMU；新增 `_pic_extent_emu()` 按真实像素比例算尺寸（封面/正文），**回退渲染器不再拉伸图片**。
- `_docx_add_image()`：补上缺失的 `from docx.oxml.ns import qn`（此前 caption 用 `qn` 会 `NameError`）。
- ReportLab 导入补 `TA_CENTER/TA_JUSTIFY`；Caption 样式色统一为灰 `#6B7280`（原先依赖 run 覆盖 `#8198AA`，漏覆盖会跑出 Office 蓝）。

**排版改动未破坏：** `test_docx_pdf_exports_have_media`（docx 含 media、PDF 正常）、`test_export_never_uses_placeholder_on_missing_image`（缺图不占位）、`test_content_blocks_place_images_after_heading`（块结构）等导出相关用例均绿。

## 4. 如何验证"排版变好"

已提供可离线运行的校验脚本 `scripts\verify_layout.py`（不调用网络/API）：

```
<venv>\python.exe scripts\verify_layout.py
```

它构造样例文章后调用 `build_docx`/`build_pdf`，再用 `zipfile` 解 `word/document.xml` 检查（全部打印真/假）：
- 正文 12pt（`w:sz 24`）、行距 1.6（`w:line 384`）、首行缩进 24pt(`w:firstLine 480`)、两端对齐(`jc both`)；
- A4 页面、标题层级 `Heading1/Heading3`；
- 配图说明含"图片来源"前缀、`资料来源` 来源块、页脚品牌横幅；
- 回退渲染器图片宽高比与原图一致（不拉伸）；
- PDF 使用中文字体（CID `STSong-Light`）且不抛异常；
- `_xml_escape` 剥离控制字符并转义标记。

并产出可目检文件到 `data\exports\sample_layout.docx` 与 `data\exports\sample_layout.pdf`（Word/PDF 排版效果验证）。

> 对照《数治周报》可直接用 Word 打开对比：主标题大小/正文字号/行距/对齐/配图说明前缀/来源块均已向成熟中文文章排版靠拢；保留了文章原生小标题层级，未照搬周报栏目编号与"数治观察"框。
